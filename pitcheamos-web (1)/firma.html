Firma para Gmail

  1. Seleccioná la firma de abajo, desde el logo hasta la última línea (o Cmd + A dentro del recuadro blanco).
  2. Copiala (Cmd + C).
  3. En Gmail: Configuración → Ver toda la configuración → General → Firma → Crear nueva → pegala (Cmd + V).
  4. Elegila como predeterminada para mensajes nuevos y respuestas, y guardá abajo de todo.
